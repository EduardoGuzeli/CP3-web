# 🏍️ MotoGarage

Um site moderno e dinâmico de loja de motos desenvolvido para apaixonados por velocidade, design e tecnologia.  
O projeto foi criado com foco em experiência visual, responsividade e organização de conteúdo utilizando tecnologias web.

![Preview do Projeto](https://github.com/github.png)

---

# 🚀 Sobre o Projeto

O **MotoGarage** é uma aplicação web desenvolvida como projeto acadêmico com o objetivo de simular uma loja virtual de motos.

O site apresenta:

- Página inicial moderna
- Catálogo de motos
- Página sobre a empresa
- Cards personalizados
- Layout responsivo
- Navegação intuitiva
- Efeitos visuais com CSS e JavaScript
